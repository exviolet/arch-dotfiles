# Фон панели в Omarchy 4.5

Проверено по релизу v4.5.0 и ветке `quattro` 13 ноября 2026 года.

- **Clear** рисует прозрачную поверхность без подложки, градиента или линии вдоль края. При переходе в Clear панель держит прежний фон до получения цвета текста, затем одновременно меняет цвет и убирает фон. [Рендер полосы](https://github.com/omacom/omarchy/blob/v4.5.0/shell/plugins/bar/Bar.qml#L1700-L1711) · [Переключение](https://github.com/omacom/omarchy/blob/v4.5.0/shell/plugins/bar/Bar.qml#L1384-L1456)
- **Цвет в Clear** выбирается между двумя цветами темы, `bar.text` и общим `background`. ImageMagick берёт первый кадр обоев, масштабирует и обрезает его по центру под размер экрана, вырезает полосу панели и уменьшает её до одного пикселя. Скрипт сравнивает контраст обоих кандидатов с этим RGB по формуле относительной яркости. Результат общий для всех виджетов. Вызов из QML не передаёт монитор, поэтому скрипт по умолчанию берёт размеры первого монитора из `hyprctl`. На пёстром фоне контраст в конкретной точке может отличаться от расчётного. [QML-вызов](https://github.com/omacom/omarchy/blob/v4.5.0/shell/plugins/bar/Bar.qml#L1411-L1420) · [Расчёт цвета](https://github.com/omacom/omarchy/blob/quattro/bin/omarchy-bar-text-color#L38-L119)
- **Glassy** использует обычный текст темы и тематический фон с альфой не выше 0,35. Размытие делает Hyprland только в этом режиме. **Opaque** использует обычный фон темы. Двойной левый клик по свободному месту проходит цикл Clear → Glassy → Opaque, выбранный режим хранится в `shell.json`. [Цвета панели](https://github.com/omacom/omarchy/blob/v4.5.0/shell/plugins/bar/Bar.qml#L78-L93) · [Цикл и переключение blur](https://github.com/omacom/omarchy/blob/quattro/bin/omarchy-bar#L204-L268)

Базовая толщина полосы Omarchy составляет 26 логических пикселей по горизонтали и 28 по вертикали. У нашей панели толщина 46 пикселей в обеих ориентациях. [Размеры Omarchy](https://github.com/omacom/omarchy/blob/v4.5.0/shell/Commons/Style.qml#L307-L321) · [Размер нашей панели](quickshell/services/PanelPlacement.qml)

У нас `Rail.qml` анализирует полосу отдельно для каждого монитора, выбирает чистый чёрный или белый и при разбросе яркости рисует контрастный градиент. В матовом режиме фон имеет альфу 0,88. Для вида ближе к Omarchy стоит сохранить выборку по мониторам, в Clear убрать подложку целиком и применять один цвет темы, выбранный по контрасту. В Glassy можно дать цвету темы альфу около 0,35 и запросить размытие только для полосы панели. Установленные Niri 26.04 и Quickshell 0.3.2 поддерживают это через `BackgroundEffect.blurRegion`, а для остальных режимов размытие снимается значением `null`. Размытие всего окна панели захватило бы и область, отведённую под выдвижной блок.
